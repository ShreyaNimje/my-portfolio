## 📖 Overview
Uber Clone is a full-stack ride-sharing application that replicates the core booking experience of Uber — from live location tracking to fare estimation and ride confirmation. It's built to demonstrate real-time data flow between rider and driver interfaces along with map-based geolocation services.

### ✨ Features
* **Live Location Tracking:** Real-time map updates for rider and driver positions.
* **Ride Booking Flow:** Pickup/drop-off selection with fare estimation.
* **User Authentication:** Separate flows for riders and drivers.
* **Trip History:** Persistent record of past rides.
* **Responsive Interface:** Optimized for both desktop and mobile use.
