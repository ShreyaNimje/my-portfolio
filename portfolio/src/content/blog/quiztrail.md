## 📖 Overview
QuizTrail is a web-based quiz platform developed using PHP and MySQL. It enables users to practice Multiple Choice Questions (MCQs), monitor their learning progress, compete on a leaderboard, and access downloadable study materials. 

The application includes authentication, quiz management, score tracking, and an admin interface for uploading resources and questions.

### ✨ Features

**👤 User Module**
* User Registration & Login
* Secure Session Management
* Personalized Dashboard
* Change Password & Logout

**📝 Quiz Module**
* Browse Quiz Categories
* Timed MCQ Quizzes
* Instant Result Generation
* Score Tracking & Performance Summary

**🏆 Leaderboard**
* Ranking based on average score
* Highest score tracking
* Total quiz attempts & User performance statistics

**📚 Resources**
* Download PDF Study Materials
* Admin uploaded learning resources
* Organized resource library
