## 📖 Overview
The Financial Analysis Pipeline is an end-to-end data analytics system built to ingest, process, and model financial datasets. It combines automated data cleaning with machine learning-driven forecasting to surface actionable insights, then renders the results through interactive Plotly visualizations for fast, intuitive interpretation.

### ✨ Features
* **Automated Data Ingestion:** Structured pipeline for cleaning and preparing raw financial data.
* **Predictive Modeling:** Scikit-Learn models for trend analysis and forecasting.
* **Interactive Visualizations:** Plotly-powered charts for exploring metrics dynamically.
* **Statistical Insights:** Correlation and risk analysis across financial indicators.
* **Modular Design:** Reusable pipeline components for new datasets or metrics.
