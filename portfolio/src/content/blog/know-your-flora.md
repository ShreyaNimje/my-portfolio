## 📖 Overview
Know Your Flora is an interactive and beautifully designed web application dedicated to providing detailed plant information. Developed with a robust PHP and MySQL backend, it features a highly user-friendly UI designed to educate users on various plant categories.

### ✨ Features
* **Plant Categories:** Organized structure for easy browsing of different flora.
* **Animated Sections:** Engaging UI animations to enhance the user experience.
* **Contact/Query Form:** Direct communication channel for users.
* **Database Integration:** Seamless PHP + MySQL data management.
* **User-friendly UI:** Clean, intuitive, and responsive design.

### 🛠️ Technologies Used
* HTML5
* CSS3
* PHP
* MySQL

### 📂 Project Structure
* `assets/` - Contains images, stylesheets, and scripts.
* `code/` - Core PHP and HTML logic.
* `screenshots/` - Visual documentation of the interface.
* `report-presentation/` - Project documentation and slides.
